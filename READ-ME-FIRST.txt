========================================================
 AEPICK POPUP LUCKY DRAW  -  작업물 패키지
 (2026-08-06 시점 / 출장 휴대용)
========================================================

[ 먼저 알아두실 것 ]
--------------------------------------------------------
  이 패키지는 **개발 진행 중인 상태**입니다.
  Beauty DNA 때의 "시연용 완성본"과 성격이 다릅니다.

  실행해서 게임을 처음부터 끝까지 돌려볼 수 있고
  운영자/어드민 화면도 모두 동작합니다. 다만 아래는
  아직 확인되지 않았습니다.

    - 실제 설치 PC에서의 성능 (개발 PC 기준 측정만 완료)
    - 8시간 연속 운영 안정성
    - Windows 키오스크 모드 설정
    - 연출 방식 A/B 최종 결정 (두 방식 다 구현되어 있음)

  자세한 근거와 수치는 docs/ 폴더에 있습니다.


[ 1단계 ] Node.js 설치  (최초 1회, 인터넷 필요)
--------------------------------------------------------
  https://nodejs.org  접속 -> LTS 다운로드 -> 설치

  * 반드시 22.13 이상이어야 합니다.
    (내장 SQLite를 쓰는데 22.13 미만에서는 실행되지 않습니다)
  * 이미 설치돼 있으면 버전만 확인하세요.


[ 2단계 ] 이 폴더를 원하는 위치에 두기
--------------------------------------------------------
  압축을 푼 폴더를 아무 곳에나 두면 됩니다.
  (예: 바탕화면 또는 C:\AEPICK-LD)

  ※ Dropbox / OneDrive 폴더 안은 피하세요.
    동기화가 파일을 잠가서 빌드가 실패합니다.
    (개발 중에도 실제로 겪은 문제입니다)


[ 3단계 ] 실행
--------------------------------------------------------
  START.bat  더블클릭

  - 처음 실행하면 패키지를 자동 설치하고 화면을 빌드합니다.
    (인터넷 필요, 3~5분. 이때 한 번만 걸립니다)
  - 이후에는 몇 초 내에 켜집니다.
  - 브라우저가 자동으로 열립니다.


[ 4단계 ] 게임 해보기
--------------------------------------------------------
  키오스크   http://localhost:8788/kiosk/
  어드민     http://localhost:8788/admin

  대기화면에서 게임을 시작하려면:

   1) 화면 **왼쪽 위 모서리를 2초간 길게 누르기**
      (숨겨진 운영자 진입 지점입니다. 눈에 보이지 않습니다)
   2) PIN  1234  입력
   3) [1회 플레이 시작]  -> 실제 재고를 차감하는 정식 플레이
      [테스트 세션 열기] -> 등급을 지정해 원하는 결과만 확인
                            (재고 차감 없음, 통계 제외)

  플레이 화면에서는 하단 조작부의 좌/우 버튼으로 집게를 옮기고
  가운데 큰 버튼으로 하강시킵니다. 12초가 지나면 자동으로 내려갑니다.

  ※ 결과(등급)는 서버가 먼저 확정하고 물리는 그것을 표현만 합니다.
    조작을 잘한다고 좋은 등급이 나오지 않습니다. 의도된 설계입니다.


[ 화면이 안 나올 때 ]
--------------------------------------------------------
  * 키오스크 주소가 백지로 나옴
    -> 빌드가 안 된 상태입니다. apps\kiosk\dist 폴더를 지우고
       START.bat 을 다시 실행하세요.

  * "Node.js 22.13 or newer is required"
    -> Node 버전 문제입니다. 1단계를 다시 확인하세요.

  * 포트 8788 이 이미 사용 중
    -> 다른 프로그램이 쓰고 있습니다. 그 프로그램을 끄거나,
       START.bat 을 메모장으로 열어 npm start 앞줄에
       set PORT=9788  을 추가하세요.


[ 데이터 ]
--------------------------------------------------------
  처음 실행하면 server\data\ 에 데이터베이스가 자동 생성되고
  기본 확률/재고가 들어갑니다. 별도 준비가 필요 없습니다.

  개발 중 쌓인 테스트 데이터는 패키지에 넣지 않았습니다.
  (참여 기록 2만여 건이 들어 있어 통계가 왜곡됩니다)

  초기화하려면 server\data\ 폴더를 통째로 지우고 다시 실행하세요.


[ 외부에 공유하려면 (선택) ]
--------------------------------------------------------
  SHARE-ONLINE.bat  더블클릭

  임시 공개 주소가 만들어집니다 (*.trycloudflare.com).
  창을 닫으면 주소가 사라집니다.

  * 최초 1회 cloudflared 설치가 필요합니다:
      winget install Cloudflare.cloudflared

  * 실행할 때마다 운영자 PIN과 어드민 키를 **새로 만들어** 씁니다.
    기본값(1234 / aepick-admin)은 이 문서에 적혀 있으므로
    인터넷에 그대로 노출하면 안 됩니다.
    화면에 표시되는 값을 쓰세요.

  * 주소를 아는 사람은 누구나 접속합니다.
    실제 플레이는 재고를 차감하므로, 보여주기용이면
    운영자 패널에서 [테스트 세션]을 쓰세요.

[ 개발을 이어서 하려면 ]
--------------------------------------------------------
  npm run dev:server     서버 (8788)
  npm run dev:kiosk      키오스크 개발 서버 (5174, 코드 수정 즉시 반영)
  npm test               단위 테스트
  npm run e2e            API 통합 테스트 (서버가 켜져 있어야 함)
  npm run autoplay       물리 자동 검증 (브라우저 없이 실행)

  ※ 개발 중에는 5174, 빌드본 확인은 8788/kiosk/ 입니다.
    둘을 헷갈리면 "고쳤는데 반영이 안 된다"가 됩니다.

  측정 도구는 tools\ 에 있습니다. 화면을 눈으로 판단하지 않고
  수치로 맞추기 위해 만든 것들입니다.

    bench.mjs       렌더 성능 (효과별 단가)
    palette.mjs     구슬 색을 레퍼런스와 비교
    wallsweep.mjs   벽 톤을 레퍼런스와 맞춤
    lightfield.mjs  박스 조명 분포
    sharpness.mjs   선명도
    kiosk-shot.mjs  화면 캡처 (헤드리스로 전체 플로우 조작)

  이 도구들은 크롬과 로컬 개발 서버가 필요합니다.
