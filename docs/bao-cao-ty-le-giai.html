3. Phát hiện từ QA — cần lưu ý khi đề xuất lại

Nguồn: docs/04_검증보고서.md (dòng 153–171, mục §5 "정책 변경 권고") — mô phỏng 900 khách × 200 lượt.

Nếu chỉ áp dụng "pacing" (giãn tỷ lệ theo khung giờ) cho giải 1–3 như kế hoạch gốc, tỷ lệ trúng vẫn sụp mạnh về cuối ngày:

62.9% (giờ đầu) → 17.8% (giờ cuối)

Nguyên nhân: giải 4 cạn kho ở khách thứ 597 vì số lượng (120) ít so với lượng khách dự kiến — giải có số lượng lớn mới là giải chi phối đường cong, không phải giải 1–3.

→ Khuyến nghị của QA: nếu số lượng giải thật vẫn thấp gần seed hiện tại, cần áp pacing cho cả 5 giải, và re-verify bằng npm run sim khi có số liệu giải thật.

5. Cách mở trang admin để điều chỉnh tỷ lệ

Nguồn: server/src/index.ts, server/src/routes.ts (dòng 28, ADMIN_KEY), server/src/pages.ts (tab "확률 설정").

  1. Khởi động server — từ thư mục gốc repo, chọn 1 trong 2 cách: 
    npm run dev:server

    hoặc chạy trực tiếp START.bat (double-click) — tự kiểm tra Node.js, cài package lần đầu, build kiosk rồi chạy npm start và tự mở /kiosk/.

    Cả hai đều chạy server ở port 8788, tự seed database nếu chưa có dữ liệu.

    ⚠️ START.bat chỉ tự mở màn chơi (/kiosk/), phải tự gõ thêm /admin. PIN "1234" nó hiển thị là Operator PIN (dùng cho vận hành), không dùng được cho mục sửa tỷ lệ — mục đó vẫn cần đúng admin key ở bước 3.

  2. Mở trang admin: 
    http://localhost:8788/admin
  3. Đăng nhập — ô "관리자 키 / 운영자 PIN", nhập admin key mặc định: 
    aepick-admin
    Lấy từ biến môi trường ADMIN_KEY, mặc định 'aepick-admin' nếu không set — muốn đổi thì set ADMIN_KEY=xxx trước khi chạy npm run dev:server.
  4. Vào tab "확률 설정" (Cài đặt tỷ lệ) — form nhập % từng giải (t1–t5, miss), tự tính tổng và chặn publish nếu tổng ≠ 100.000%, kèm cấu hình pacing bên dưới.

Sau khi sửa tỷ lệ/số lượng xong, chạy lại npm run sim -- --pacing-tiers t1,t2,t3,t4,t5 để kiểm tra đường cong trúng thưởng trước khi chốt số liệu thật.

Để đề xuất số liệu thật: cung cấp ngân sách giải + số lượng khách dự kiến, chỉnh trong Admin (rule version), sau đó chạy npm run sim -- --pacing-tiers t1,t2,t3,t4,t5 để kiểm tra đường cong trúng thưởng trước khi chốt.
